从 WorkerRuntime 开始

点选图中任意类，或使用上方下拉框。Tab / Enter 也可操作节点。

Runtime 装配 Client、Executor 和共享 Session；Client 管连接与执行 Task，Executor 管任务编排，Session 管持久恢复证据。

    范围与读法

    33 个类均来自 app/worker/**/*.py 的 ClassDef。包外 CodingAgent 和两个函数锚点不计入；第三方基类写在节点内。

    箭头表达静态关系，不表达调用时间顺序。未展开所有协议消息和第三方类型；完整边界见配套说明。

    用于简化结构时，先核对这些边界

    共享状态与连接生命周期

    Client 与 Executor 持有同一个 WorkerSession。WebSocket 重连不重建执行 Task；进程丢失后的编码任务不会凭 journal 盲目重跑。

    WorkerSession 同时负责 journal、停止/归档证据与历史查询路由。是否拆分应结合重连、结果重放、取消用例判断。

    回调依赖与函数边界

    Client 将自身以 tool_caller 传给 Executor；INITIAL 中的 WorkerMCP 经 FlowToolCaller 回调 Client。Executor 不长期持有 Client。

    Amp 编码和历史导出共用 run_amp()。VCS、凭据、gh、prompt 和原子写文件主要由函数实现，类数量不能代表全部复杂度。

    两份持久证据与更新分支

    SessionState.workspace 与 WorkspaceSlot.binding 记录同一分配身份；journal 证明执行与清理，manifest 证明目录槽位所有权。

    self_update 是 CLI 独立分支；InstalledPackage 和 UpdateError 没有被 Runtime 持有。建议保留这条边界。
